# AI Agent 概述

## 什么是 AI Agent

AI Agent（智能体）是一个能**感知环境、自主决策、采取行动，并朝目标持续推进**的智能系统。

它通常由大模型充当“大脑”，再配合工具、记忆和执行循环，形成完整工作流：

1. **感知**：读取用户输入、工具返回结果、历史记忆和外部系统状态  
2. **推理 / 规划**：判断当前目标与下一步动作  
3. **行动**：调用 API、检索知识、执行代码、操作业务系统等  
4. **观察与迭代**：根据反馈继续执行，直到完成任务或触发退出条件  

可以把 Agent 概括为：

> **大模型负责思考，工具负责行动，记忆负责上下文，循环负责把任务做完。**

常见特征包括：

- **目标导向**：围绕明确任务推进，而不是单轮闲聊  
- **自主性**：在少人工干预下连续完成多步操作  
- **工具使用**：通过外部能力补足模型短板  
- **可迭代**：失败后可重试、修正策略或请求人工介入  

## Agent 和传统 AI 应用的区别

| 维度 | 传统 AI 应用 | AI Agent |
|------|--------------|----------|
| 交互方式 | 单次输入 → 单次输出 | 多轮感知 → 决策 → 行动闭环 |
| 能力边界 | 主要依赖模型自身知识 | 可调用工具、系统、外部数据 |
| 任务形态 | 回答问题、生成内容 | 规划并执行完整任务 |
| 状态管理 | 通常无持久任务状态 | 有记忆、上下文和执行状态 |
| 失败处理 | 返回错误或结束 | 可重试、换路径、升级人工 |
| 典型例子 | 聊天机器人、文本分类、摘要 | 自动客服办单、代码助手、运营自动化 |

核心差异不在“是否用了大模型”，而在于：

- 传统 AI 更像**问答或预测服务**  
- Agent 更像**能做事的执行系统**  

一句话：传统 AI 帮你“想清楚”，Agent 还要帮你“做下去”。

## Agent 的典型应用场景

- **智能客服与业务办理**：理解诉求后查订单、改地址、发起退款，必要时转人工  
- **研发助手**：读代码、定位问题、改文件、跑测试、提交变更建议  
- **知识工作自动化**：调研资料、汇总报告、整理会议纪要、生成周报  
- **运营与增长**：监控数据异常、生成分析结论、触发告警或运营动作  
- **个人助理**：日程管理、邮件处理、信息检索与多步骤待办执行  
- **多智能体协作**：规划、执行、审查分工，适合复杂长链路任务  

适合做成 Agent 的任务通常具备这些特点：目标明确、可拆成多步、需要调用外部系统，且允许一定程度的自动重试。
